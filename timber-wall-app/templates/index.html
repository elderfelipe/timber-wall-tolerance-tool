Tolerance Results

Warping vs. Flatness

Bow and crook (defined "relative to a measurement length of 2000mm" per EN 336/DIN 4074/DIN EN 14080) checked against DIN 18202's flatness limit at that same 2m distance — comparing both figures at the one span they were each actually defined at, rather than rescaling either. Since 2m falls between DIN 18202's tabulated 1m and 4m columns, the limit shown is linearly interpolated between them (per DIN 18202's own footnote: intermediate values follow a published curve, not a step function) — a disclosed approximation using only the source's real data points, not a digitization of that curve. This check covers only a 2m span within the stud. The source standards give no rule for extrapolating bow/crook to a stud's actual full height when that differs from 2m, so none is assumed here — see the note below the results.

Tolerance Performance

1 · Deviation budget by source

Where the combined tolerance on each dimension actually comes from: the framing member's own manufacturing tolerance vs. the DIN 18202 assembly-level allowance.

2 · Permitted deviation vs. target size

How DIN 18202's permitted linear deviation (a step function of target size) and the material's own length tolerance scale with wall size. The dashed markers show your current wall.

3 · Stud positional tolerance: fabrication method sensitivity

Datum-referenced (jig/laser-line) layout keeps positional tolerance constant per stud. Chained (stud-to-stud tape) layout accumulates linearly — this is why jig-based fabrication matters for stud spacing accuracy. "Datum-referenced" here is modeled using DIN 18202's alignment-deviation-for-columns value as a proxy for a stud — an analogy, not a literal citation.

4 · Stud-count sensitivity

What actually changes as you add studs: bay spacing shrinks, and the chained positional tolerance at the far stud grows linearly. Bow/crook are per-member material properties tied to grade/class, not to stud count, so they're covered separately below (Warping vs. Flatness) rather than shown here.

Unverified flags mark tolerance values the tool used that were ambiguous in the source PDF extraction — check the warnings box after building a frame.
