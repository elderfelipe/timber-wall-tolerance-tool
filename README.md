# timber-wall-tolerance-tool
Parametric tolerance analysis tool for automated timber wall production, developed for Holistic Tolerance Analysis in Automated Prefabricated Housing: From Material in-put to Robot Processing

This tool was developed as part of the Master's thesis [Holistic Tolerance Analysis in Automated Prefabricated Housing: From Material in-put to Robot Processing], Elder, RWTH Aachen, 2026.
